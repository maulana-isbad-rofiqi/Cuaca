Advanced Settings

Web-Push (server-based)

Masukkan VAPID Public Key dan alamat server push-mu. Sistem akan mendaftarkan subscription ke server.

Petunjuk singkat (server)
Server harus menyimpan subscription JSON yang dikirim dari browser, lalu gunakan web-push (Node.js) atau library setara untuk mengirim push menggunakan VAPID keys. Contoh: web-push sendNotification(subscription, payload).

Radar / Satelit (Advanced)

Kamu bisa menggunakan tile provider (contoh: RainViewer tiles) atau integrasi iframe dari penyedia satelit. Masukkan URL tile/iframe dan API key jika diperlukan.
